# Spectral-fit visualization trial

These figures are a first trial of four complementary spectral-fit views.
They were generated by
`../plot_spectral_fit_visualization_trials.py`. The detailed example is truth
state 033, chosen because its retrievals show the compensating behavior under
discussion. The ensemble views admit a state only when corrected and
uncorrected files for all perturbations 01--11 are present and carry
`retrieval_complete=1`.

1. `01_residual_atlas_band*.png` shows one wavelength-resolved atlas per band.
   Each state has a main row containing the median over noisy perturbations
   01--10 and an adjacent thin row for noiseless perturbation 11. Corrected and
   uncorrected residuals share a +/-3 color scale; their difference uses +/-5.
   The left strips encode surface, aerosol case, SIF case, and truth XCO2. An
   `x` marks rows containing a nonconverged retrieval.
2. `02_state033_spectral_fit_card.png` shows, for every band, the measurement
   and terminal forward model, normalized residuals, and the
   uncorrected-minus-corrected normalized-residual spectrum. Black curves are
   the noiseless retrieval; colored curves and ribbons are the median and
   16th--84th percentiles over noisy perturbations.
3. `03_state033_rrs_absorption_budget.png` separates the noiseless discrepancy
   into the truth signal, the part absorbed through retrieved-state motion,
   and the terminal residual difference. All three use one pooled noise scale,
   `sqrt((sigma_uncorrected^2 + sigma_corrected^2)/2)`.
4. `04_compact_fit_quality_summary.png` compares corrected and uncorrected
   `sqrt(reduced chi-squared)` per band. Circles are noisy and squares are
   noiseless retrievals; color identifies surface and fill identifies aerosol
   presence.

Retrieval files store `final_residual = F(x) - y`. The plotting script checks
that identity for every selected file, then deliberately displays `y - F(x)`.
It also requires exactly common wavelength and band-index grids across every
selected product and checks truth metadata against `true_states.dat`.

Run from the repository root with:

```bash
python3 RRS_XCO2/inversion/plot_spectral_fit_visualization_trials.py
```

Use `--state N` to substitute another fully paired state for the detailed
figures.
